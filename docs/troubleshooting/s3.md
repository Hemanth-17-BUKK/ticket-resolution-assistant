# S3 Troubleshooting

## Issue 1 - Upload Failure

### Cause

Missing IAM permissions.

### Resolution

Verify:

S3CrudPolicy

attached to Lambda.

---

## Issue 2 - Download URL Not Working

### Cause

Object does not exist.

### Resolution

Verify object:

aws s3 ls s3://ticket-resolution-assistant-attachments/attachments/ --recursive

---

## Issue 3 - 403 Access Denied

### Cause

Expired presigned URL.

### Resolution

Generate a new URL using:

GET /tickets/{ticketId}

---

## Verification Commands

List Files

aws s3 ls s3://ticket-resolution-assistant-attachments/attachments/ --recursive

Download File

aws s3 cp s3://ticket-resolution-assistant-attachments/attachments/<file> .

---

## Best Practices

Store metadata in DynamoDB.

Store files in S3.

Use presigned URLs for downloads.
